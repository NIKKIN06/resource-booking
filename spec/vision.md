# Інформаційна система управління бронюванням ресурсів

## Призначення

Інформаційна система управління бронюванням ресурсів призначена для автоматизації процесу резервування та обліку доступних ресурсів.

Система забезпечує користувачам можливість переглядати доступні ресурси, перевіряти їх зайнятість і створювати, змінювати або скасовувати бронювання.

Адміністратор системи має можливість керувати переліком ресурсів та контролювати створені бронювання.

## Ресурси

Переговорні кімнати та окремі одиниці обладнання. Кожна кімната або одиниця обладнання є окремим ресурсом.

## Погоджене базове правило

BR-01: Один ресурс не може мати два активні бронювання, часові інтервали яких перетинаються. Правило діє для всіх користувачів, включно з адміністратором.

## Статус документа

Початковий опис задуму системи. Не є остаточною SRS. Використовуватиметься як вхідний матеріал для SKED-діалогу та створення специфікації в ЛР-2.
