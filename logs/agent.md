# Обраний кодинговий агент

Інструмент: Antigravity Extension 1.3.0 для Visual Studio Code.
Клас: кодинговий агент, інтегрований в IDE.
Автентифікація: Google-акаунт.

Доступ до репозиторію: через відкриту у VS Code локальну папку resource-booking.

Операції для цієї роботи:
- перегляд структури проєкту;
- читання файлів;
- внесення змін у файли після дозволу користувача.

Обмеження:
- агент не виконує коміти та злиття;
- агент не змінює файли поза погодженим завданням;
- власник перевіряє результат через git status і git diff;
- рішення про фіксацію та прийняття змін ухвалює власник.
