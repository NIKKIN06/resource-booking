## Причина конфлікту

У двох гілках від спільного початкового стану змінено той самий
рядок документації.

Людина вручну додала адміністративний виняток для моделювання
навчального конфлікту.

Кодинговий агент уточнив правило відповідно до BR-01:
перетини активних бронювань одного ресурсу заборонені,
зокрема для адміністратора.

## Еталон для рішення

spec/vision.md, правило BR-01:
один ресурс не може мати два активні бронювання,
часові інтервали яких перетинаються.
Правило діє для всіх користувачів, включно з адміністратором.

## Рішення

Залишено формулювання агента, яке забороняє перетини
без адміністративного винятку.

Ручну зміну відхилено, оскільки вона суперечить BR-01.
Підставою рішення є відповідність погодженій вимозі,
а не авторство або час внесення зміни.

## Питання до ЛР-2

Цей конфлікт не виявив прогалини у вимозі:
BR-01 явно поширюється на адміністратора.
Додаткове уточнення для розв’язання цього конфлікту не потрібне.
